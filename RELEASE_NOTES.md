Unofficial experimental Wii port based on Loz by Aldo J. Nunez.

Download `boot.dol` and follow the repository README to prepare SD data from your own unmodified PRG0 ROM and the original Zelda Remastered V1.3 pack. The executable alone is not a complete game. No ROM, extracted game data, HD artwork or audio is distributed here.

This alpha includes a cave drawing optimization, but physical Wii cave stutter remains unconfirmed. It does not implement all Mesen HD pack rules or automatically apply the pack's IPS/Redux changes. See README for controls, installation, build instructions and known limitations.

`THIRD_PARTY_NOTICES.txt` contains the code and library notices accompanying the executable. Source is available at this tag; generated lookup headers and game assets must be produced locally.
